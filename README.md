# 🛒 E-Commerce Website

A modern and responsive **E-Commerce Website** built using **Python, Django, HTML, CSS, Bootstrap, JavaScript, and MySQL**. This project provides a complete online shopping experience with separate Admin and User panels.

---

## 🚀 Features

### 👤 User Features

* User Registration & Login
* Secure Authentication
* Browse Products
* Category-wise Product Listing
* Product Details Page
* Add to Cart
* Update Cart Quantity
* Remove Items from Cart
* Checkout System
* Order Management
* Responsive UI

### 🛠️ Admin Features

* Admin Login
* Dashboard
* Manage Categories
* Manage Brands
* Manage Products
* Product Image Upload
* Manage Orders
* Manage Users

## ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/kashyaptiwari444-cell/E-COMMERCE-WEBSITE.git
```

Move into the project folder

```bash
cd E-COMMERCE-WEBSITE
```

Create a virtual environment

```bash
python -m venv venv
```

Activate virtual environment

**Windows**

```bash
venv\Scripts\activate
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run migrations

```bash
python manage.py makemigrations
python manage.py migrate
```

Start the development server

```bash
python manage.py runserver
```

Open your browser

```
http://127.0.0.1:8000/
```
